Project 04

CSS Accordion

A responsive FAQ-style accordion built with semantic HTML, details, summary, and state-based CSS.

Why use details and summary?

They create an accessible accordion without JavaScript. The browser already understands how to open and close each item.

What does the open selector do?

The selector details[open] lets the CSS style only the expanded item, including its title, icon, and content.

How is the plus and minus icon made?

A pseudo-element on summary shows a plus sign by default and changes to a minus sign when the item is open.

What makes it responsive?

The layout uses flexible width, readable spacing, and a small media query so the accordion stays comfortable on narrow screens.

What did this project practice?

Semantic HTML, CSS variables, pseudo-elements, attribute selectors, hover states, open states, and responsive spacing.
